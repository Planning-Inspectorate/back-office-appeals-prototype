  • Note for development to include aria labels for when the message "Packaging files ready for download. Refresh in a few minutes." updates and the files become available
  • Possible improvement to mark the download package with a message equivalent to 'updates available' based on the presence of updates posted to the case history - this work would require
Possible improvements In future, we may explore notifying users when a downloaded ZIP package could be out of date and prompting them to request an updated version.

This was not included in MVP due to uncertainty around reliably detecting changes that affect ZIP contents. Potential inputs such as broadcasts, updated dates and case history are not currently considered sufficiently comprehensive.

Implementing this now could result in both false positives (prompting updates when none are needed) and false negatives (failing to identify changes that affect package contents, such as some document redactions).

If needed, this feature remains a potential post-MVP enhancement and could be revisited once a more reliable detection approach has been defined and validated.
